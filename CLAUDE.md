# CLAUDE.md

Guidance for AI coding assistants working in this repository.

## Overview

**Multi-property interactive map**: `/` is the single-engine MapLibre atlas (`v2/`, see the V2 section) and `/classic` is the original Leaflet app; both serve several properties, each with its own boundary, project zones, panels, and photo galleries. Current properties: `howard` (1320 Baldwin Rd, Ojai — 13 proposal zones), `sulphur-mountain` (Eco-Village — 18 zones, V1 data from `SacredRebel/EcoVillage-map`), `keris-property` (3 zones), `chers-property` (2 zones), and `black-mountain-ranch` (63 real county parcels drawn as lot territories + 6 Lemuria vision zones).

## Architecture

- **`properties/*.js`** — one module per property: `{ id, name, shortLabel, labelChip, center, zoom, footerTitle, footerInfo[], cta { heading, paragraph, contacts[], buttons[] }, panel { title, html }, boundary[], zones[], lots?[], lotStyle? }`. Adding a property = new module + import + append to `PROPERTIES` in server-complete.js.
- **`server-complete.js`** — Express + whole frontend in a template literal. `PROPERTIES` array is injected via the `PROPERTIES_PLACEHOLDER` token (JSON). Aggregates `PROJECT_ZONES` / `PERMANENT_PROPERTY_LINES` feed `/api/health` and `/api/project-zones`.
- **Frontend flow:** map starts at `fitBounds` of all boundaries (overview). Below zoom 13.5 the `#map` div gets `.overview-mode`: per-property **label chips** show (click → flyTo property). Zone markers are shown per property — visible once `zoom >= thatProperty.zoom - 2.5` (`updateMarkerScale`), so a huge ranch shows icons while a small neighbor's stay tucked. Each property renders 3 stacked polylines (glow + animated rainbow + 30px invisible hit line); boundary click → `openPropertyPanel(propId)` which injects `prop.panel.html` and calls `loadPropertyImages(propId)`.
- **🌍 3D terrain mode (V0.13):** `#earth-toggle` (under the mode pill) opens a fullscreen MapLibre GL overlay (`#earth3d`): Esri World Imagery draped over AWS terrarium elevation (`setTerrain`, exaggeration 1.35, maxPitch 80), free/keyless sources. MapLibre 4.7.1 lazy-loads from unpkg on first open; the GL map is destroyed on exit. Rebuilt each open, so it inherits the Current/Vision state: zone markers filter via `window.zoneVisibleInMode`, names via `window.zoneView`, chips honor `visionLabelChip`. Property boundaries render as gold-glow + violet lines, ranch lots as thin white plat lines; chips fly cinematically (`flyTo` pitch 62). 2D map got Google-Earth-feel physics: `zoomSnap 0.25`, long parabolic `flyTo`/`flyToBounds` flights, glide inertia. **V0.14 gesture bridge (one connected map):** middle-mouse-hold-drag on the 2D map (or a parallel two-finger drag on touch — spread change < 45px, |dy| > 38px) opens 3D and the SAME drag keeps driving pitch/bearing — deltas accumulate in `earthPendPitch/Bearing` until GL `load` fires (`earthReady`), then apply live at 0.35°/px; middle-drag orbits inside 3D too (canvas `mousedown` button 1 → shared window-level move handler); `close3D()` hands the camera back (`map.setView(center, glZoom+1)`); gestures are suppressed while `window.positionEditActive`. `#earth3d-gearth` opens the exact current camera in Google Earth web (`earth.google.com/web/@lat,lng,0a,DISTd,35y,Hh,Tt,0r`, no API key). `window.earth3dRef` exposes the GL map for tests. **V0.15 globe + portals:** MapLibre 5.24.0 with `projection: {type:'globe'}` — zooming out curves the map into a planet in space (CSS starfield `#earth3d-stars` under the transparent-space GL canvas, atmosphere halo via style `sky` with `atmosphere-blend` fading by z11; terrain confirmed working WITH globe; the one benign console warning is `calculateFogMatrix is not supported on globe projection`). Every property panel gets a `🌀 Enter the Vision` `.portal-btn` (appended after `panelData.html`): `window.enterPortal(propId)` closes the panel, switches to Vision (`applyMode(true)`), and opens 3D with `earthDiveTo` set → cinematic 4.2s globe dive. Portals are the future doorway to the playground-cosmos-view gamifications (react-globe.gl/three.js app — not yet linked). **V0.16 polish:** `zoomSnap 0` continuous wheel (tuned debounce/px), flight durations auto-scale with distance (fixed `duration:` removed from chip/recenter flights), markers rescale on `zoom` not just `zoomend`. 3D is KEPT ALIVE on exit (close3D hides + syncs camera back, never `remove()`s; `build3D()` reopen path = `resize` + `jumpTo` from 2D + `buildMarkers3D()` only if `earthBuiltMode !== visionMode` + `earthEntry()`); `webglcontextlost` tears down for a clean rebuild; engine pre-warms in background 2.5s after load (queued `loadMapLibre`, silent onerror unless overlay open); `#earth3d-loading` pulsing orb while cold; middle-drag orbit has rAF inertia (`orbitVel` decay ×0.9). Loading: `preconnect` to arcgisonline/s3/unpkg/raw.githubusercontent/wsrv.nl; gallery images go through wsrv.nl resizing CDN (`cdnImg(src, w)` — 1400px mains webp q82, 240px thumbs) with `data-raw` + `onerror` fallback to the original; first slide eager rest `loading="lazy"`; the preload-all loop now warms only 2 slides per subcategory; lightbox untouched (full-res + ±1 preload). Vercel already brotli-compresses (~494KB → ~110KB) — no middleware. **V0.19 perf overhaul (the "terrible laggy 3D" fix):** the ~50 zone markers moved OFF the DOM onto ONE GPU symbol layer — `makeZoneIcon(emoji,col)` rasterizes each unique emoji badge to a canvas → `map.addImage` (cached in `zoneImgCache`, reset on context loss), a `zonesrc` GeoJSON source + `zones3d` symbol layer (`icon-image:['get','icon']`, zoom-interpolated size, allow-overlap) built once on `load`; `buildMarkers3D()` now just `setData`s the source + rebuilds the 6 DOM property chips (kept as markers — negligible). Clicks via `map.on('click','zones3d')` → popup. Render resolution capped: `pixelRatio: Math.min(devicePixelRatio,1.5)` (the retina/4K tearing+lag fix), `fadeDuration:0`, `antialias:false`. The whole 3D world now PRE-BUILDS silently at page load: `prebuild3D()` (2.2s after load) adds `.prebuilding` (full-size but `opacity:0;z-index:-1`) so the GL canvas warms tiles/terrain/shaders/zone layer, then on `idle` drops back to `display:none` still alive — first open is just `resize`+`jumpTo`+fly-in. `open3D` promotes an in-flight prebuild to a real open; `build3D` branches ready-reopen / in-flight / fresh-construct. `sampleFps3D()` (once, after first real open) medians ~55 frames and now only **logs** the result — the V0.19.1 hotfix removed the `setTerrain(null)` auto-drop, which was firing during the opening fly-in and permanently flattening the terrain for everyone; `build3D()` also re-asserts `setTerrain` on every reopen and exaggeration is 1.5. `.zone3d` CSS now unused.

## V2 — the single-engine rebuild (`/v2`, since V0.26)

`docs/engine-blueprint.md` is the spec. **`v2/`** is a Vite + TypeScript app on **MapLibre GL 5.24 only** — 2D and 3D are the same scene (2D = pitch 0), so there is one coordinate pipeline and one place a positioning bug could live. `cd v2 && npm install && npm run build` type-checks (`tsc --noEmit`) and writes the bundle to **`public/v2/`**, which is COMMITTED (Vercel runs no build step) and served by the classic Express app: `app.use('/v2', express.static(...))` with immutable caching for `assets/`, plus `GET /api/properties` (the `PROPERTIES` array, positions applied). `vercel.json` carries `includeFiles: ["public/v2/**", "data/**"]` so the function bundle contains them. Glyphs are self-hosted (`v2/public/fonts/Open Sans Semibold/*.pbf`, copied into the build) — no dependency on the MapLibre demo server.

- **`src/layers/registry.ts`** — the same 36 layers / 7 groups / 32 flights / 7 historic-topo editions as V0.25, typed (`OverlayDef`, `FlightDef`). `z` is draw order, `maxZoom`/`minZoom` are LEAFLET zooms (256-tile) — convert with `ml()` (MapLibre zoom = Leaflet − 1) for camera comparisons; for a `px:256` source the registry `maxZoom` IS the MapLibre source `maxzoom` (tile-zoom), so scale-limited CGS sheets overzoom instead of going blank.
- **`src/layers/transport.ts`** — `svcBase` / `exportBase` / `exportTail` / `wmsUrl` / `rasterSource(def)`: the one URL builder (`{bbox-epsg-3857}` per tile). Verified against the servers' own grid in V0.25 (NCC 0.995 at zero shift).
- **`src/engine/map.ts`** — `Engine`: style with `base-esri`, a `raster-dem` terrarium source (`maxzoom 14`) used for BOTH `setTerrain` (exaggeration 1.5) and a GPU `hillshade` layer (visible only with terrain on), two invisible anchor layers: overlays are inserted before **`ov-anchor`** in declared `z` order (`beforeFor(z)`), property vectors before **`prop-anchor`**. `setBase(id)` crossfades: the new raster layer is added just under `hillshade` at opacity 0 and transitions to 1 (`raster-opacity-transition` 320 ms); every other `base-*` layer is removed on the next `idle` (3.5 s fallback), always keeping the base current *at settle time* (`baseSettle` guards rapid scrubbing). `setFlight(i, immediate)` debounces 160 ms. `setOverlay/toggleOverlay/setOpacity` (per-layer `raster-opacity`), `parts` → `ov-<id>-p<i>`, `image` kind → image source + surveyed vectors (`-line`, `-ease`, `-mon` from `/api/survey/...`, cached in `surveyVec`), `setHistYear()` rebuilds `histtopo` into the alternate slot (`ov-histtopo~`) and removes the old on idle. Globe projection below zoom 6.5 only (`projectionFor`), mercator for property work. `setQuality()` → `setPixelRatio` (1 / min(dpr,1.5) / dpr). Events via a tiny typed `Emitter` (`base`, `overlays`, `opacity`, `histYear`, `terrain`, `view`, `loading`, `fps`).
- **`src/data/properties.ts`** — `PropertyLayer`: fetches `/api/properties`, stitches boundary segments to rings (exact geometry, the V0.24 rule), `props` (fill + gold glow + violet line), `lots` (white plat lines), `zones` (one symbol layer; emoji badges rasterised once via `map.addImage`, `text-field` names from the self-hosted glyphs, `minzoom 11.5`, mode filter Today/Vision), six HTML chips as `Marker`s. `onSelect(kind, payload)` → the HUD inspector.
- **`src/ui/hud.ts`** + **`src/style.css`** — the Empire-Earth-style shell: top bar (brand, crumb, year pill, TODAY/VISION pill, `?`), left **dock** (base radios incl. "County aerial flights", then a `<details>` per group with `1–7` hotkeys, ⓘ per row, live filter box), right **inspector** (tab *What you see* = one block per active or ⓘ-pinned layer with source link, opacity slider and the legend from `<service>/legend?f=json` via `src/layers/legend.ts`; tab *Parcel* = property/zone/lot card + the county dossier rendered from `/api/dossier`), bottom **timeline** (aerial flights 1945→2025 and historic topo 1903→1995, big year readouts, `[` `]` step), bottom-right **controls** (compass/N, 3D/T, terrain/X, layers/L, inspector/I, quality, fps, tile-activity dot). Hotkeys: WASD pan · Q/E rotate · R/F tilt · +/− zoom · T · X · N · L · I · H (historic topo) · Space (mode) · G (Google Earth) · Esc · `?`.

## Git-backed layout saving (V0.6)

- `data/zone-positions.json` = live source of truth for icon positions; applied over module defaults at server boot (module positions are the fallback if the file is missing).
- `POST /api/save-positions` `{ pin, positions: {propId: {zoneId: [lat,lng]}} }`: checks `EDIT_PIN` env var, validates ids against `PROPERTIES`, applies in-memory, then commits the file to GitHub via the Contents API using `GITHUB_TOKEN` (fine-grained PAT, Contents R/W on this repo; `GITHUB_REPO` env overrides the default repo slug). Missing env vars → 501; the editor then guides users to the Capture/export fallback.
- The editor's 🔒 Save button drives this; PIN is remembered in `localStorage.ojaiMapEditPin` (cleared on 401).
- When baking positions manually, update BOTH the property modules and `data/zone-positions.json` so defaults and live file agree.

## Key gotchas

- Frontend lives in a template literal — keep `\${...}` / `` \` `` escaping intact; the injection token is exactly `PROPERTIES_PLACEHOLDER`.
- Boundary segments per property must chain (segment N's last coord = segment N+1's first); client stitches and closes each loop.
- `preferCanvas: true` — boundary/circle vector layers are canvas-rendered (no per-path CSS), zone markers + label chips are DOM divIcons.
- `properties/*.js` panel `html` strings are injected into the panel verbatim — plain string-concat HTML, no `<script>` tags allowed (would break the JSON-in-`<script>` injection).
- Vercel: git-connected project `howard-property-dev` auto-deploys `main`; `/images/*` 302s to THIS repo's raw URLs (for future Howard photos).
- `images/` is the photo-upload tree (`images/<property>/<zone>/{current,vision}/`, property gallery = `images/<property>/property/current/`); new files must be listed in `image-urls.js` to show up.
- After ANY server/frontend patch, run the served-page check: boot the server, curl `/classic`, extract the inline `<script>`, `node --check` it — `node --check server-complete.js` alone does NOT parse the embedded frontend.
